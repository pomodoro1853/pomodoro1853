### tutorial-10: webフレームワークLaravelの実践的に使いこなそう
- [middleware-app-practice](https://github.com/pomodoro1853/middleware-app-practice) - カスタムミドルウェアを使って、管理者のみアクセスできる「管理者専用ページ」を保護するもの。

- [eloquent-app-practice](https://github.com/pomodoro1853/eloquent-app-practice) - ブログシステムのモデル作成
- [setup-app-practice](https://github.com/pomodoro1853/setup-app-practice) - Laravel Sail と Docker を使って、開発環境を構築
- [security-app-practice](https://github.com/pomodoro1853/security-app-practice) - CSRF保護付きお問い合わせフォームの作成
- [validation-app-practice](https://github.com/pomodoro1853/validation-app-practice) - ユーザー登録フォームを作成し、バリデーションで定めているルールのみの入力で登録することができるMVC作成（ビューは提供ファイル）
- [relation-app-practice](https://github.com/pomodoro1853/relation-app-practice) - タグによる絞り込み機能実装 読み取り専用のindexとshowのみのMVC機能実装
- [database-app-practice](https://github.com/pomodoro1853/database-app-practice) - マイグレーションでデータベースにテーブルを作成し、シーダーでダミーデータを挿入、ダミーデータを挿入したデータベースをコントローラーとルーティングとビューファイルを駆使して http://localhost/products に表示
- [profile-app-practice](https://github.com/pomodoro1853/profile-app-practice) - 自己紹介ページを作成
- [blade-app-practice](https://github.com/pomodoro1853/blade-app-practice) - 提供されたBladeファイルを動かすためのコントローラーとルーティングの作成
